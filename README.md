# Personal Expense Tracker

A responsive, feature-rich web application built for the Level 2 Hackathon - Fundamentals of Web Development.

**Key Features:**
* **Dashboard & Analytics:** Real-time balance calculations and interactive expense charts using Chart.js.
* **Full CRUD Operations:** Add, edit, and delete income and expense transactions.
* **Advanced Filtering:** Search by description, category, transaction type, and date range.
* **Data Persistence:** All transactions and custom categories are saved securely in the browser's Local Storage.
* **Pro Features:** Integrated Dark Mode and one-click CSV data export.

**Technologies Used:**
* HTML5, CSS3 (Custom styling with CSS Variables), Vanilla JavaScript.
